
# Omarchy Pocket Rotate

Omarchy Pocket Rotate aims to make switching between normal and 180-degree orientations simple and convenient on the GPD Pocket 3 running Omarchy Linux, Hyprland, and Quickshell.

## Features

- **Top-bar integration:** A dedicated button in the Omarchy shell for quick access.
- **One-click toggle:** Switch between normal and 180-degree orientations.
- **Hyprland integration:** Designed around the display configuration used by the GPD Pocket 3.
- **Non-destructive configuration:** Aims to preserve existing Omarchy settings and touchscreen calibration rules.
- **Open source:** Intended to be easy to inspect, customize, and extend.

## Project Status

**Experimental — work in progress.**

The project is being developed and tested for Omarchy 4 on the GPD Pocket 3. Reliable live touchscreen rotation, synchronization between display and touch orientation, and status feedback still need to be implemented and verified.

Other hardware configurations and Omarchy versions have not yet been tested.

## Goals

The goal is to provide a lightweight, maintainable solution for rotating both the built-in display and touchscreen without manually editing configuration files every time the device orientation changes.

Contributions, testing, and feedback from other Omarchy and GPD Pocket users are welcome.

## Disclaimer

Use this software at your own risk. Back up your configuration files before installation. This project is community-developed and is not an official part of Omarchy or GPD.
